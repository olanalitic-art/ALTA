# Ресайз сайдбаров ALTA IDE

Спецификация интерфейса, 16.11.2026.

## Размеры

| Параметр | Значение |
|---|---|
| Левый и правый сайдбар | 248–420 px |
| Ширина по умолчанию | 248 px для каждой панели |
| Минимальная ширина центральной области | 512 px |
| Ширина разделителя (Splitter, `AltaIDE_Resize`) | 10 px |
| Минимальная ширина приложения | 1380 px |

## Правила

- Ширину сайдбара меняют перетаскиванием вертикального разделителя.
- Каждый сайдбар ограничен диапазоном 248–420 px.
- Центральная область не становится уже 512 px. Если расширение сайдбара нарушит это, расширение останавливается.
- Центральная область занимает всё оставшееся место.
- Фактический максимум сайдбара может быть меньше 420 px из-за ограничения центральной области.

## Расчёт

Две открытые панели, два разделителя по 10 px:

```
W_center = W_viewport − W_left − W_right − 20
W_left,max = min(420, W_viewport − W_right − 512 − 20)
```

Для правого сайдбара формула симметричная. Если правого сайдбара нет, вычитается только один разделитель.

## Контрольный пример

Приложение 1380 px, оба сайдбара по 420 px: 1380 − 420 − 420 − 20 = 520 px. Это больше 512 px, конфигурация допустима.

## Критерии приёмки

- Ширина каждого сайдбара не меньше 248 px и не больше 420 px.
- Перетаскивание разделителя не сужает центральную область меньше 512 px.
- При ширине приложения 1380 px допустима конфигурация 420 / 520 / 420 px с двумя разделителями по 10 px.
- Ширина панелей по умолчанию 248 px.

## Дополнительно в реализации

Этого нет в спецификации, добавлено для удобства. Нужно подтвердить.

- Клавиатура: разделитель получает фокус по Tab. Стрелки меняют ширину на 10 px, со Shift на 50 px. Home ставит минимум, End — максимум.
- Двойной клик по разделителю возвращает ширину по умолчанию, 248 px.

## Где реализовано

- `02_components/ide/AltaIDE_Resize/sidebar-resize.js` — общая логика для любого экрана.
- `03_master` — мастер-макет использует её для левого сайдбара.
