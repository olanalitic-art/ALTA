Превью: [Открыть демонстрацию](https://nastya-nikki.github.io/ALTA/02_components/code-editor/AltaCodeEditor_CodeCanvasFull/preview.html)

## Файлы

- `index.html` — отдельный пример.
- `preview.html` — карточка компонента.
- `code-canvas-full.css` — оформление из актуальной Figma.
- `code-canvas-full.js` — подтверждённые конфигурации.
- `assets/figma-source.json` — исходные свойства и привязки.
- `../../../01_foundations/tokens/alta-code-editor.css` — токены и цепочки алиасов.
- `../../../01_foundations/tokens/figma-alta-code-editor-variables.json` — значения, режимы и использованные стили Figma.
- `../../../01_foundations/runtime/code-editor.js` — общая логика локального примера.

Составной пример из Figma отображается как локальная область кода с прокруткой. Компиляция, запуск и подключение отладчика не выполняются. Вложенная подсветка сохранена в составе исходника без создания отдельных компонентов исключённого раздела Syntax.
