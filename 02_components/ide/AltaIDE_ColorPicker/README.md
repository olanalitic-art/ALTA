# AltaIDE_ColorPicker

Панель выбора цвета и прозрачности.

Превью: [Открыть демонстрацию](https://olanalitic-art.github.io/ALTA/06_site/components/color-picker/preview.html)  
Источник: [Color Picker, node 203886:340](https://www.figma.com/design/axdKFZbeqNIfskP18KDs32/?node-id=203886-340).  
Статус: реализовано, ожидает проверки дизайнером.  
Дизайн, переменные и варианты прочитаны 30.10.2026.

## Файлы

- `index.html` — отдельный пример.
- `preview.html` — карточка вариантов и демонстрация.
- `color-picker.css` — геометрия и токены из Figma.
- `color-picker.js` — подтверждённые конфигурации.
- `assets/figma-source.json` — свойства и измерения.
- `assets/*.png` — оригинальные шкалы и текстура прозрачности из Figma.
- `../../../01_foundations/tokens/` — общие токены и режимы.
- `../../../01_foundations/fonts/` — исходные шрифты.
- `../../../01_foundations/runtime/widgets.*` — общая техническая логика элементов выбора.

Изменение данных в интерактивном примере — демонстрационный сценарий. Исходные значения и варианты в таблицах сохранены.

В исходнике значения каналов, HEX и положение ползунков не всегда соответствуют друг другу. Начальные значения и статические шкалы сохранены; синхронизация RGBA/HSV после ввода является демонстрационным сценарием. RGB/HSV меняет данные в существующих полях без добавления новых визуальных вариантов.
