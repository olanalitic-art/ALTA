# AltaIDE_Pagination

Элемент перехода между страницами.

Превью: [Открыть демонстрацию](https://olanalitic-art.github.io/ALTA/06_site/components/pagination/preview.html)  
Источник: [AltaIDE/Pagination, node 185489:22717](https://www.figma.com/design/axdKFZbeqNIfskP18KDs32/?node-id=185489-22717).  
Статус: реализовано, ожидает проверки дизайнером.  
Дизайн, переменные и варианты прочитаны 30.10.2026.

## Файлы

- `index.html` — отдельный пример.
- `preview.html` — карточка вариантов и демонстрация.
- `pagination.css` — геометрия и токены из Figma.
- `pagination.js` — подтверждённые конфигурации.
- `assets/figma-source.json` — свойства и измерения.
- `assets/*.svg` — неизменённые иконки из Figma.
- `../../../01_foundations/tokens/` — общие токены и режимы.
- `../../../01_foundations/fonts/` — исходные шрифты.
- `../../../01_foundations/runtime/widgets.*` — общая техническая логика элементов выбора.

Изменение данных в интерактивном примере — демонстрационный сценарий. Исходные значения и варианты в таблицах сохранены.

Интерактивный пример объединяет три подтверждённых типа и использует пять демонстрационных страниц. У исходного набора есть только вариант `Theme=Dark`; отдельная тема Light не добавлена.
