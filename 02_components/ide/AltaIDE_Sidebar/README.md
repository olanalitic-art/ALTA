## Файлы

- `index.html` — отдельный пример.
- `preview.html` — карточка компонента.
- `sidebar.css` — оформление из дизайн-контекста.
- `sidebar.js` — подтверждённые варианты.
- `assets/` — исходные идентификаторы и оригинальные ресурсы Figma.
- `../../../01_foundations/tokens/altaide-composed.css` — проверенные токены и цепочки алиасов Figma.
- `../../../01_foundations/runtime/shell.js` — общая логика локального примера.

Полные значения переменных, режимы и цепочки алиасов проверены в текущей Figma и сохранены в `../../../01_foundations/tokens/figma-altaide-composed-variables.json`.

Структура строк и иконки сохранены из конкретных экземпляров Figma. Выбор и навигация работают локально; дополнительные ветви не создаются.
