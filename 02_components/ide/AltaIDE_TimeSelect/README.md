# AltaIDE_TimeSelect

Столбец выбора значения времени.

Превью: [Открыть демонстрацию](https://olanalitic-art.github.io/ALTA/06_site/components/time-select/preview.html)  
Источник: [Time Select, node 200193:8724](https://www.figma.com/design/axdKFZbeqNIfskP18KDs32/?node-id=200193-8724).  
Статус: реализовано, ожидает проверки дизайнером.  
Дизайн, переменные и варианты прочитаны 30.10.2026.

## Файлы

- `index.html` — отдельный пример.
- `preview.html` — карточка вариантов и демонстрация.
- `time-select.css` — геометрия и токены из Figma.
- `time-select.js` — подтверждённые конфигурации.
- `assets/figma-source.json` — свойства и измерения.
- `../../../01_foundations/tokens/` — общие токены и режимы.
- `../../../01_foundations/fonts/` — исходные шрифты.
- `../../../01_foundations/runtime/widgets.*` — общая техническая логика элементов выбора.

Изменение данных в интерактивном примере — демонстрационный сценарий. Исходные значения и варианты в таблицах сохранены.

Прокрутка использует общую реализацию ScrollVertical. Размеры полосы и ползунка в составе Time Select сохранены как в исходном экземпляре Figma.
