# AltaIDE_Link

Текстовая ссылка, ссылка со стрелкой или внешняя ссылка.

Превью: [Открыть демонстрацию](https://olanalitic-art.github.io/ALTA/06_site/components/link/preview.html)  
Источник: [AltaIDE/Link, node 185293:1270](https://www.figma.com/design/axdKFZbeqNIfskP18KDs32/?node-id=185293-1270).  
Статус: реализовано, ожидает проверки дизайнером.  
Дизайн, переменные и варианты прочитаны 30.10.2026.

## Файлы

- `index.html` — отдельный пример.
- `preview.html` — карточка вариантов и демонстрация.
- `link.css` — геометрия и токены из Figma.
- `link.js` — подтверждённые конфигурации.
- `assets/figma-source.json` — свойства и измерения.
- `assets/*.svg` — неизменённые иконки из Figma.
- `../../../01_foundations/tokens/` — общие токены и режимы.
- `../../../01_foundations/fonts/` — исходные шрифты.
- `../../../01_foundations/runtime/widgets.*` — общая техническая логика элементов выбора.

Изменение данных в интерактивном примере — демонстрационный сценарий. Исходные значения и варианты в таблицах сохранены.

Адрес перехода в Figma не задан. В демонстрации ссылки перехватываются; у реальной ссылки адрес задаётся стандартным атрибутом `href`. У исходного набора есть только вариант `Theme=Dark`.
