Как показать порядок исполнения?

Четыре варианта на одной схеме управления вентиляцией. Откройте любой вариант, чтобы рассмотреть его и попробовать выбор нод.

A

Общий порядок исполнения

Развернуть

Номера всех нод появляются при выборе любой ноды.

B

Порядок выбранной цепочки

Развернуть

Нумеруется цепочка, необходимая для исполнения выбранной ноды.

C

Зависимости выбранной ноды

Развернуть

Выделяются зависимости; остальная схема приглушается.

D

Зависимости и дальнейшее влияние

Развернуть

Выделяются зависимости и ноды, на которые выбранная нода влияет.
