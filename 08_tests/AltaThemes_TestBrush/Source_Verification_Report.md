# Пять компонентов Alta.Themes: сверка JSON с GitLab

## Результат

Создан единый файл [alta-themes.five-components.source-verified.json](alta-themes.five-components.source-verified.json) непосредственно из скачанных исходников GitLab. Он заменяет предыдущую тестовую выгрузку из Excel для дальнейшего пилота. Предыдущие файлы не изменялись.

Источник: [Alta.Themes, зафиксированный коммит](https://rnd.owen.ru/softwaredevelopmentbureau/alta.themes/-/tree/b5e6ddac6e5c2cdc4725e906a8f607d74d79aa73/Alta.Themes).

- Ветка при обращении: `main`.
- Зафиксированный коммит: `b5e6ddac6e5c2cdc4725e906a8f607d74d79aa73`.
- FileVersion в проекте: `1.0.21`.
- Дата проверки: 25 ноября 2026 года.
- Доступ: скачивание архива конкретного коммита через авторизованный браузер пользователя.

## Что означает полное соответствие

Для выбранных пяти компонентов перенесены все описания в их основных AXAML-файлах: существующие имена, селекторы и их вложенность, свойства, значения, шаблоны, именованные темы и ссылки на ресурсы. Отдельно учтены контекстные правила из других файлов репозитория. Подключения и тематические словари сохранены как данные об источнике.

Внутри JSON находятся исходные тексты 25 файлов, необходимые для проверки описаний и общего контекста. Для каждого указаны путь, кодировка, SHA-256 и ссылка на GitLab. Совпадение этих текстов с архивом проверено побайтово: 25 из 25, то есть 100%. Обязательные для пяти компонентов описания не сокращены до списка кистей и не восстановлены по их именам.

Дополнительно проверено соответствие структурированных правил, setter, шаблонов, определений кистей, значений обеих тем и мест прямого применения исходному XML. В файле есть встроенный раздел `verification` с результатом.

Это **полное соответствие перенесённому описанию выбранной ревизии Alta.Themes**. Оно не означает проверку итогового отображения в произвольном приложении, где возможны дополнительные стили и переопределения. Avalonia и плагин Figma в этом поручении не запускались. Работоспособность селекторов не подменяется фактом их присутствия в исходнике.

## Существенные исправления по сравнению с первым JSON

1. **ToggleButton полностью описан по файлу разработчиков.** Включены Primary, SlideSwitch и именованная тема `ExpandCollapseChevroneTheme`. Ранее в каталоге были только пять кистей с префиксом Toggle.
2. **Подтверждено переиспользование именно кистей.** `ToggleButton.Primary` напрямую использует `ButtonControl*Brush`. Ранее на основании Excel можно было уверенно говорить лишь о некоторых общих цветах палитры.
3. **Button содержит дополнительные оформления.** Сохранены dialog, toolbar-контекст и классы ok/yes/no/cancel, а не только Primary и Secondary.
4. **HEX получены из исходной палитры.** Отсутствующие в Excel значения не заполнялись дизайнерскими цветами и теперь раскрыты по ресурсам Alta.Themes.
5. **Применение отделено от объявления.** Наличие Loading в имени кисти не превращено в доказательство соответствующего состояния компонента.
6. **Контекстные правила не потеряны.** Для TextBox учтены правила из AltaDesign, EditableBlock и TreeDataGrid; для ToggleButton — из ComboBox и Expander. Их цепочки владельцев сохранены, чтобы не представлять контекстное правило глобальным.

## Особенности исходника, сохранённые без исправления

- TextBox при наведении использует `TextControlBorderFocusBrush`, а не автоматически подобранный `TextControlBorderHoverBrush`.
- Рамка отмеченного CheckBox с классом Error использует `CheckBoxUncheckedBorderInvalidBrush`.
- В RadioButton есть селектор `Ellipse#CheckGlyph`, хотя в его шаблоне имена эллипсов — InnerEllipse, ExtraEllipse и CheckEllipse. Несовпадение записано как наблюдение; имя не исправлено в выгрузке.
- В ToggleButton для Knob сохранён селектор `^ Border#Knob` без добавления `/template/`.
- `RadioButtonMinHeight` используется, но его определение в AXAML скачанного Alta.Themes не найдено. Ссылка сохранена дословно, числовое значение не придумано. Внешняя тема или приложение могут предоставлять этот ресурс.

Внешние пакетные зависимости записаны из csproj. Содержимое сторонних Avalonia-пакетов в этот пилот не подмешивалось и не объявлялось исходником Alta.Themes.

## Как использовать файл

`components` содержит ровно пять выбранных компонентов. `brushes` — их ключи и определения обеих тем; `style_rules` — точные правила; `control_templates` и `control_themes` — описания шаблонов и тем; `all_resource_reference_sites` — места использования. Preview не считается применением в рабочем контроле.

`shared` содержит палитру, сведения о подключениях, индекс ресурсов и внешние зависимости. `source_files` позволяет сверить перенесённые данные с исходными текстами в том же JSON, без нескольких файлов GitLab.

Структура полей JSON — формат пилота версии 0.2.0. Имена разработчиков внутри него сохранены. Это данные для дальнейшей реализации, а не готовый алгоритм разрешения всех состояний Figma или каскада Avalonia.

На GitHub ничего не опубликовано. Следующий этап — привязка компонентов, вариантов и текущих состояний Figma к проверенным правилам этого каталога.
