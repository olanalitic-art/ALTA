# AltaThemes_TestBrush

Тестовые данные для пилота отображения кистей Alta.Themes в плагине Figma.

## Файлы

- [alta-themes.five-components.source-verified.json](alta-themes.five-components.source-verified.json) — единый каталог Button, TextBox, CheckBox, RadioButton и ToggleButton с точными именами кистей, правилами, шаблонами и значениями Light/Dark.
- [Source_Verification_Report.md](Source_Verification_Report.md) — область сверки, особенности исходника и ограничения.
- [verification.json](verification.json) — результаты проверки полноты переноса и совпадения с исходниками.

Источник данных: Alta.Themes, коммит `b5e6ddac6e5c2cdc4725e906a8f607d74d79aa73`, FileVersion `1.0.21`. Данные подготовлены и проверены 25 ноября 2026 года.

## Использование в пилоте

1. Загрузить основной JSON и проверить `schema_version` (`0.2.0`).
2. Читать пять компонентов из `components`; точное имя кисти находится в `brushes[].key`.
3. Определения Light/Dark находятся в `brushes[].themes`. Имена разработчиков не переименованы.
4. Применение проверять по `application_sites` и точным цепочкам селекторов, учитывая классы, состояния и контекст. `preview_sites` относятся только к демонстрационным примерам.
5. Не выдавать объявленный ключ без места применения как автоматически подтверждённую кисть состояния.

Данные сохраняют исходные описания пяти компонентов и необходимые общие источники. Это не готовый алгоритм распознавания Figma и не исполняемая тема Avalonia. Привязки к компонентам Figma и разрешение текущего состояния предстоит реализовать отдельно. Запуск Avalonia/Figma этой проверкой не подтверждён.
