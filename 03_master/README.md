# Мастер-макет ALTA IDE

Каркас окна ALTA IDE: то, что есть на каждом экране. Отдельные экраны в `04_layouts` собираются на его основе, в центр каждый экран кладёт своё содержимое.

Открыть: https://olanalitic-art.github.io/ALTA/03_master/

## Что входит

- **Верх окна** — меню («Файл», «Правка», «Вид»…) и тулбар: создать и открыть проект, сохранить, добавить устройство, компиляция, подключение, загрузка, запуск, отладка.
- **Сайдбар** — дерево проекта: устройство, программные блоки, менеджер задач, списки переменных, пользовательские типы. Над деревом строка «Новый проект» с кнопками.
- **Граница сайдбара** — её можно перетаскивать.
- **Вкладки открытых документов.**
- **Центр** — пустая область `data-slot="content"` для содержимого экрана.

## Что уже работает

- Дерево: выделение строки, сворачивание и разворачивание веток, навигация стрелками.
- Контекстное меню дерева: правый клик, Shift+F10 или клавиша «Меню». Стрелки, Home и End перемещают по пунктам; Enter, Esc, Tab и клик вне меню закрывают его.
- Перетаскивание границы сайдбара.

## Что докрутить дальше

- Подсказки при наведении на кнопки тулбара.
- Выпадающие меню из пунктов «Файл», «Правка»…
- Поиск по дереву и кнопки над деревом (свернуть, развернуть).
- Вкладки: переключение и закрытие.
- По решению: Status Bar внизу окна.

## Файлы

- `index.html` — композиция окна.
- `layout.css` — расположение и значения конкретного макета.
- `layout.js` — поведение: дерево, контекстное меню, ширина сайдбара.
- `components-used.json` — какие компоненты и варианты использованы.
- `assets/` — ресурсы экземпляров Figma, для которых нет точного совпадения в библиотеке.

Розовые точки 2×2 px в углах элементов — служебные метки библиотеки (`01_foundations/runtime/component-marker.css`). Они показывают, где стоит компонент.
