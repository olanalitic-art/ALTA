# AltaIDE_AutocompleteInfo

Подробная информация о подсказке автодополнения.

Превью: [Открыть демонстрацию](https://nastya-nikki.github.io/ALTA/components/ide/AltaIDE_AutocompleteInfo/preview.html)  
Источник: [AltaIDE/AutocompleteInfo, node 202319:9696](https://www.figma.com/design/axdKFZbeqNIfskP18KDs32/?node-id=202319-9696).  
Статус: реализовано, ожидает проверки дизайнером.  
Дизайн, переменные и варианты прочитаны 30.10.2026.

## Файлы

- `index.html` — пример компонента.
- `preview.html` — варианты, состояния и демонстрация по применимости.
- `autocomplete-info.css` — стили вариантов из Figma.
- `assets/figma-source.json` — свойства, измерения и ссылки на переменные Figma.
- `../../../foundations/tokens/` — общие токены с режимами и алиасами.
- `../../../foundations/fonts/` — общие шрифты.
- `../../../foundations/runtime/` — общие стили компонентов и карточек.

Прокрутка реализована нативным браузерным механизмом; исходный декоративный ползунок в интерактивном экземпляре скрывается.
