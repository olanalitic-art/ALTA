# Проверка локального прототипа

02.11.2026. Проверка через браузер по локальному HTTP.

- Каталог → Toggle → Input → Toggle: переходы работают.
- Toggle: click → aria-checked=true; пробел → false.
- Toggle: включён + disabled → disabled=true, используется toggle-185224-157.svg.
- Сброс Toggle: aria-checked=false, disabled=false.
- Input: ввод строки, ручная ошибка → aria-invalid=true; сброс работает.
- Тёмная тема сохраняется при переходе на другую страницу.
- Все SVG Toggle загружаются; ошибок JavaScript во время проверки не зарегистрировано.
- Вёрстка Toggle на 1440 и 390 px не имеет горизонтального переполнения, просмотрена визуально.

Это проверка сценариев макета; не полный аудит доступности или доказательство соответствия актуальному Figma-файлу.
