# Общие токены ALTA — 0.1.0-draft

Локальное предложение, применённое к Input и Toggle. Удалённые репозитории не изменены. Соответствие живому Figma-файлу отдельно не проверялось.

## Что считается источником

`tokens/tokens.json` — редактируемый реестр этой сборки. Из него `python3 scripts/build_tokens.py` создаёт `assets/tokens.css`. JSON использует простой локальный формат, без заявления о совместимости с внешними форматами обмена.

`reference-input.css` и `reference-toggle.css` — справочные снимки экспортов двух исходных репозиториев. Новые значения вносятся в реестр, а не поверх этих снимков. Ссылки на источники находятся в JSON.

## Три уровня

1. Базовые значения: палитра, Rubik, числовая шкала, радиусы, толщина границы.
2. Общие роли: поверхность, основной/вторичный текст, акцент, ошибка, основной текст и пояснение, расстояние до подписи.
3. Компонентные роли: фон и граница Input, фон и бегунок Toggle, геометрия каждого компонента.

Одинаковая роль меняет значение между Light и Dark. Не нужно назначать обоим компонентам одинаковую высоту: Input остаётся 28px, Toggle — 20px. Совместимость обеспечивают согласованные токены, отступы и правила композиции.

## Подтверждённое и предложенное

- Цвета и размеры компонентных ролей взяты из экспортов и измерений исходных компонентов.
- 66 парных значений совпали после разрешения ссылок; сравнение ограничено выбранными ролями Input и Toggle.
- Общие семантические роли `--color-*`, `--font-body-*`, `--font-caption-*`, `--space-*` предложены для этого макета. Их нужно оценить при согласовании дизайна.
- Файлы Rubik Regular, Medium и SemiBold взяты из `AndrewKz499/ALTA_IDE/assets/fonts`, main, 02.11.2026. Начертания 400/500/600 подключаются локально. Резервный системный шрифт используется только при невозможности загрузить Rubik.
- Геометрия Toggle перенесена в CSS; оригинальные SVG оставлены в `components/toggle/assets/` для сверки. Цвета адаптера зависят от темы.

## Имена и совместимость

Для новых компонентных ролей используйте имена с дефисами: `--input-h-padding`, `--toggle-background-active-true`. Найденные старые варианты названий сохранены как алиасы. Алиас ссылается на основное имя, а не копирует его значение.

`--num-*` сохраняет исходную шкалу; новые общие интервалы называются по роли. Измеренные ширины Input не превращаются в общую шкалу всех компонентов.

## Подключение нового компонента

1. Зафиксировать ссылку и версию/снимок источника.
2. Выписать используемые цвета, шрифты, интервалы, размеры и обе темы.
3. Сопоставить с существующими значениями и ролями. Если роль уже существует, подключить её.
4. Если найдено различие, записать оба значения и происхождение; не выбирать молча последнее по порядку подключения CSS.
5. Для специфической потребности добавить компонентную роль. Для повторяющейся потребности предложить общую.
6. Сгенерировать CSS, проверить обе темы, размеры, взаимодействия и композицию с существующими компонентами.

## Версия

Версия токенов учитывается отдельно от версии компонента и страницы документации. Текущий `0.1.0-draft` обозначает только эту локальную сборку. При изменении роли или значения нужно фиксировать затронутые компоненты и повторять их проверку.
