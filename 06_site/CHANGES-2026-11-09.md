# Изменения от 09.11.2026

Каталог обновлён по репозиторию ALTA (main, PR #14–#16).

- **Компоненты ALTA (`vendor/alta`)** обновлены из репозитория. Локальные правки каталога сохранены.
- **Светлая тема компонентов.** Подключены токены `altaide-theme.css`, `alta-cfc-theme.css` и `alta-code-editor-theme.css` со значениями Dark/Light из Figma. Ноды CFC, комментарии, деревья, DropdownOpen и редактор кода теперь светлые в светлой теме (раньше оставались тёмными).
- **Иконки.** В светлой теме подставляются `*.light.svg` с цветами Light из Figma (`assets/alta-theme-icons.js`).
- **Таблицы «Цвета».** На 30 страницах вместо одного значения теперь колонки Light и Dark. Обновлены значения, изменившиеся в Figma (Tab/Text, Search/Icons/Default). В Node Comments рамка выбранного состояния — токен `Comments/Border/Default`.
- **Основы → Цвета.** Добавлены палитры Light/SkyBlue, Cian, Orange, Rose, Purple.
- **Тёмная тема** не изменилась: скриншоты всех страниц до и после совпадают.

## Дополнение: проверка переключения темы

- Subtitle и Tooltip Editor больше не остаются тёмными в светлой теме: убраны принудительно тёмная подложка и `data-theme="dark"` на примерах.
- Основы → Иконки: плитки светлые, иконки переключаются на светлые версии. Поле Scale в TB_Vis на токене Input.
- Основы → Шрифты: пример кода в светлой теме светлый.
- Проверены все страницы в обеих темах: нет тёмных блоков, кроме намеренных, и нет битых картинок. Намеренные тёмные блоки: Menu Link (ссылка меню стоит на тёмной полосе меню), тёмный образец тени на странице «Цвета», нажатая Button Primary.
