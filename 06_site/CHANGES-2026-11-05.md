# Обновление 05.11.2026

Эталон оформления — существующая страница Input. Её содержание сохранено; в навигацию добавлены новые страницы.

## Кнопки

- В Button Primary и Button Secondary разделены «Состояния» и «Варианты».
- В состояниях оставлены пять примеров на размере L без иконки.
- В вариантах отдельно показаны размеры L / M и четыре положения иконки.
- Заглушки заменены на оригинальные значки Plus и Close из Nastya-nikki/ALTA. SVG сохранены без изменения; исходники и варианты указаны в `button-icon-sources.json`. Цвет иконки следует цвету компонента через альфа-маску.
- Новый раздел добавлен в текущую и межстраничную навигацию.

## Страницы

- **Hints:** исходная текстовая подсказка, назначение, опубликованные свойства и параметры. Раздел состояний отсутствует, поскольку отдельных состояний в GitHub нет.
- **Radio:** оформление по примеру Checkbox, реальные десять сочетаний Selected / State, интерактивный выбор, пример Radio Label, размеры и цвета. В примерах сохранены оригинальные SVG с фиксированными цветами.
- **Tooltip Help:** варианты Command / Help, интерактивное переключение, описание реально существующих частей и свойств.
- **Tooltip Editor:** четыре типа сообщения и четыре положения указателя; только 16 сочетаний из определения GitHub. Сохранена единственная исходная тема Dark.
- **Banner:** Info / Success / Warning / Error, действия и закрытие исходного компонента, восстановление через сброс.

Версии релизов, неподтверждённые состояния и сценарии не добавлялись. Параметры и цвета получены из опубликованных данных GitHub с разрешением цепочек переменных. Снимки источников и идентификаторы зафиксированы в `source.json` новых страниц.

Ссылки на все пять страниц включены в каталог и боковое меню. Полная реализация библиотеки на GitHub не изменялась: обновлён локальный каталог из предоставленного архива.

## Проверено

Обе темы оболочки; ширины 1440 и 390 px; загрузка ресурсов; все варианты интерактивных примеров; сброс; выбор и блокировка Radio; закрытие и восстановление Banner; ссылки каталога и навигации. Ошибок JavaScript, отсутствующих ресурсов и горизонтального переполнения не обнаружено.

Для просмотра откройте `index.html`.

## Правки после визуальной проверки

- Сетки примеров больше не объединяют ячейки: недостающие позиции последней строки заполняются отдельными пустыми ячейками. Границы сохраняются при любом числе колонок.
- Отступы подзаголовков, шапки страниц, ссылки на источники и таблицы параметров приведены к оформлению Input. Таблицы имеют рамку, заголовки, выравнивание, колонку токена и образцы цветов.
- Во всех строках Tooltip Editor и Banner восстановлены разделители. Между предыдущим блоком и «Положением указателя» добавлен отступ.
- В карточке Segment показан один активный сегмент. Порядок в каталоге и меню: Segment → Segment Control → Segment Control 2.
- Проверены 23 страницы на ширинах 1440, 1024 и 390 px; отдельно просмотрены обе темы семи обновлённых страниц. Неполных сеток, пропавших рамок, переполнения страницы и ошибок JavaScript не обнаружено.
