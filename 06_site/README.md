# ALTA Design System — предполагаемый общий репозиторий

Локальный статический каталог дизайн-системы ALTA. Эталон оформления описания компонента — Input. Изменения от 05.11.2026 перечислены в CHANGES-2026-11-05.md.

## Просмотр

Откройте `index.html` в браузере. Сборка, установка зависимостей и сеть для отображения не нужны. Либо из этой папки запустите `python3 -m http.server 8080` и откройте http://localhost:8080.

## Структура

```text
index.html                       Общий каталог
components.json                  Реестр компонентов и ссылок на источники
assets/
  site.css                       Общая оболочка и оформление документации
  site.js                        Темы и навигация
  tokens.css                     Токены из исходного репозитория Input
components/
  input/
    preview.html                 Страница документации
    input.css                    Стили исходного компонента
    demo.js                      Настройки рабочего примера
  toggle/
    preview.html                 Страница документации
    toggle.js                    Локальная интерактивная обвязка SVG
    demo.js                      Настройки рабочего примера
    assets/                      Четыре оригинальных SVG и figma-source.json
    source/                      Справочные копии README, CSS и JS источника
```

Каждая страница содержит пример, параметры, общие токены, состояния, применение, версии и ссылку на свою папку в GitHub. Дерево компонентов расположено справа. На узком экране вместо дерева показаны ссылки Input / Toggle. Тема сохраняется при переходах между страницами, если браузер разрешает localStorage.

## Источники

- Input: https://github.com/AndrewKz499/ALTA_IDE/tree/main/components/input
- Toggle: https://github.com/olanalitic-art/ALTA/tree/main/02_components/ide/AltaIDE_Toggle

Материалы прочитаны из main 02.11.2026. Input CSS и токены скопированы из первого репозитория. SVG Toggle сохранены без изменения геометрии и цветов. Rubik 400 / 500 / 600 включён локально и подключён к обеим страницам и каталогу.

Оригинальные SVG Toggle имеют фиксированные цвета и сохранены для сверки. В актуальном макете используется CSS-адаптер `components/toggle/toggle.css` на общих токенах: он поддерживает обе темы. Дополнительных размеров или вариантов дизайна Toggle не добавлено. Фокус клавиатуры и переключение состояния реализованы в локальной обвязке. Сценарии использования и подписи предложены для макета; они не означают реализацию этих функций в ALTA.

## Статусы и версии

README источника Toggle сообщает: реализовано, ожидает проверки дизайнером. Это не утверждение о принятии текущего прототипа. Релизные версии источников не установлены; записи 0.1.0, 0.1.1 и 0.2.0 демонстрируют предложенный формат. Версия макета документации — v0.1.

## Добавление компонента

Создайте папку `components/<name>/`, страницу `preview.html`, стили и поведение компонента. Добавьте запись в `components.json`, карточку в `index.html` и ветку в навигацию страниц. В текущем прототипе HTML статический: JSON служит реестром, меню автоматически из него не генерируется.

## Проверка

Проверены переходы каталога и дерева, Input (ввод, ошибка, сброс), Toggle (клик, пробел, включённое недоступное состояние, сброс), сохранение темы, загрузка SVG. Проверено отсутствие горизонтального переполнения на ширинах 1440 и 390 px. Дополнительные результаты в `VALIDATION.md`.

Удалённые репозитории не изменялись. Для публикации содержимое этой папки можно отдельно перенести в согласованный репозиторий и настроить GitHub Pages.


## Общие токены (v0.1.0-draft)

`tokens.html` — страница общих основ с образцами и совместным примером Input / Toggle.

- `tokens/tokens.json` — единый редактируемый реестр для локальной сборки.
- `assets/tokens.css` — результат генерации; вручную не редактируется.
- `scripts/build_tokens.py` — генерация и проверка отсутствующих/циклических ссылок.
- `tokens/comparison.json` — сопоставление 66 значений из двух экспортов.
- `tokens/reference-input.css` и `reference-toggle.css` — справочные снимки источников.
- `assets/fonts/` — локальные Rubik Regular / Medium / SemiBold.
- `TOKENS.md` — происхождение, уровни и правила пополнения.

После правки JSON: `python3 scripts/build_tokens.py`. В HTML подключается один `assets/tokens.css`. Разные исходные token CSS одновременно не подключаются.
