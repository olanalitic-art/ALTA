# Витрина ALTA Design System

**Открыть сайт:** https://olanalitic-art.github.io/ALTA/06_site/

Витрина — это сайт-каталог компонентов ALTA. У каждого компонента своя страница: живой пример, варианты и состояния, цвета для светлой и тёмной темы, параметры и ссылка на исходник в [`02_components`](../02_components).

## Что внутри

```text
index.html          Главная: список всех компонентов
tokens.html         Основы: токены
foundations/        Основы: цвета, шрифты, иконки, логотипы
components/<имя>/   Страница компонента (preview.html) и её файлы
assets/             Оформление сайта: стили, скрипты, шрифты, иконки
vendor/alta/        Копия библиотеки, на которой работают примеры
history/            Заметки о прошлых обновлениях витрины
```

Сейчас в витрине 155 страниц компонентов: IDE, CFC и Code Editor.

## Как обновляется

Сайт обновляется сам примерно через минуту после того, как изменения слиты в `main`. Витрину правим только здесь, в репозитории. Старая копия на компьютере больше не используется.

## Связь с компонентами

- В README каждого компонента в `02_components` ссылка «Превью» открывает его страницу в этой витрине.
- Со страницы витрины ссылка на GitHub ведёт в папку этого компонента в `02_components`.

## Что ещё не доделано

- Примеры берут компоненты из своей копии `vendor/alta`, а не прямо из `02_components`. Поэтому копия может отставать от репозитория. Позже её нужно убрать.
- `components.json` описывает только 7 компонентов из первого прототипа. Меню сайта из него не строится.
- У 24 страниц не хватает файлов `*-def.js`, так было и до переноса.
